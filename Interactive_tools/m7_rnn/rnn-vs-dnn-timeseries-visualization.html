Table or Sequence?

A dense network does not see a time series. It sees a table: rows and columns. A recurrent network gets the same numbers as a sequence, one step at a time. Shuffle the rows, scramble the columns, mix up one time step, and see what each network really depends on.

What does each network lean on?

Here is a way to find out. Take one column, or one time step, and mix up its values between the rows. Every row keeps everything else. Then let the trained network forecast again. If the error barely moves, the network was not using that piece. If it doubles or triples, the network depended on it.

Count the weights

A dense network needs a weight from every input to every unit of its first layer, so it grows with the window. A recurrent network uses the same weights at every time step, so the window can be any length.

1 · A dense network sees 12 separate columns

It has no idea that the last column is the most recent month. Scramble the columns, train again, and it does just as well. Whatever order there is, it has to learn from the data.

2 · Shuffling the rows is fine

Every row carries its own 12 months of history inside it. So the time order is preserved, but only indirectly: inside each row, not between the rows.

3 · The RNN really carries its first step

The month it leans on most is the one from 12 months back: the same month last year. That is the first value it reads, so it has to hold it in its state for 11 more steps. See that state move in Inside the recurrent cell.

4 · Memory has a length and a depth

The length is the number of time steps the network reads. The depth is the number of slots in the state, which Keras calls units. A longer window costs an RNN no extra weights, but how far back it can really remember is another matter: see the gradient lab.

Data: Box and Jenkins monthly international airline passengers, January 1949 to December 1960, thousands. Every row holds 12 consecutive months and the month after them, 132 rows, the last 12 (targets in 1960) kept for testing. The dense network is 12 inputs, then 32 and 16 units (ReLU), then 1 output, 961 weights, trained on the raw table for 100 passes. One copy was trained with the columns in time order and one with the columns scrambled the same way in every row. The recurrent network is a simple RNN with 16 units (tanh), 305 weights, trained on the monthly change in the logarithm. Each stored network is the run with the middle test error out of 10, its weights are in this page, and the forecasts and the mixing tests are computed in your browser. The mixing tests use the training rows: the dense network's error is a mean absolute percentage error, and the RNN's is the mean absolute error of the predicted monthly change, shown as a multiple of its normal value.
