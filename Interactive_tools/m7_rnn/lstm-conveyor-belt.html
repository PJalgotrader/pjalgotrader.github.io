The LSTM Conveyor Belt

An LSTM adds a second line that runs straight through time: the cell state. Think of it as a conveyor belt. Three gates decide what stays on the belt, what gets written onto it, and what is shown. First set the gates yourself. Then watch a trained LSTM set them on a memory test.

A gate is not a switch. It is a dimmer: 0% blocks everything, 100% lets everything through. Every slot of the memory has its own three dimmers. Here you set them. In a real LSTM the network computes them fresh at every step, from the new input and the previous state.

1 · A belt next to the state

The cell state is long-term memory. A value can step onto the belt at one time step, ride along untouched, and step off many steps later. The hidden state is working memory: what the cell is saying right now.

2 · The one line that makes an LSTM

New cell state = forget gate × old cell state + input gate × candidate. Keep what is still useful, add what is new. Notice the plus sign: the old memory is scaled and added to, not pushed through weights and a tanh at every step.

3 · When, not what

The gate positions are not fixed. They are computed at every step from the data. So the network does not learn to forget slot 3. It learns when to forget slot 3. In the memory test, the input gate opens at the marked numbers and nowhere else.

4 · Seeing is not remembering

A simple RNN reads all 100 numbers too, but its state is rewritten at every step, so the first marked number fades before the second arrives. That fading is the vanishing gradient, measured in the gradient lab.

The memory test is the adding problem of Hochreiter and Schmidhuber (1997): every step has a random number between 0 and 1 and a marker, the marker is 1 at exactly two steps (one in each half of the list), and the target is the sum of the two marked numbers. Always answering 1 gives a mean squared error of about 0.167. The networks here are a simple RNN (tanh) and an LSTM with 16 units each, trained with the same budget (Adam, up to 15,000 steps, gradient clipping at 1), three runs for every length.
