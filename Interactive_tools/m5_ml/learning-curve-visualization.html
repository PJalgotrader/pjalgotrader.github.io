The Learning Curve

Do we need more data, or a different model? Pick a model, then grow the training set and watch where training and validation error settle. The gap between them is variance. How far they sit above the noise floor is bias.

Variance shrinks with n. Bias does not.

Press play on degree 10. At n = 10 the faint fits fly everywhere and the gap is huge. By n = 150 they have calmed down. Now try degree 1: the fits agree with each other from the start, but they all miss the curve in the same way, at every n.

The noise floor is a hard limit.

On average, validation error can approach σ² but not go below it, because no model can predict the random noise. A small validation set gives a noisy score that can dip under the floor by luck. Raise the validation size and the orange curve steadies. Drop σ to 0.5 and the floor falls, so even the small cubic term suddenly matters and degree 2 starts to look biased.

Data: y = 0.15x³ − 0.5x² + 0.3x + 3 + ε, with x uniform on [−3, 3] and ε ~ N(0, σ²). Degree 3 is the shape that generated the data (green dot on the selector). Each point on the learning curve is the median over 40 independent training sets of size n; the shaded bands show the 10th to 90th percentile. The red benchmark always predicts the average of the training y values and is scored on the same validation sets. Each training set gets its own fresh validation set, sized as a percentage of n (30% by default), so small n also means a small, noisy validation score. Switching degree, λ, σ, or validation size reuses the same random draws, so comparisons are fair.
